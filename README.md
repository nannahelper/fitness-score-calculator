# NanNa 体测分数计算器

静态、无后端的大学生体质健康测试成绩计算器，部署于 GitHub Pages 与 `static.lilystudio.space`。

## 功能

- 大学生男/女、大一/大二与大三/大四综合成绩；
- BMI、肺活量、50 米、立定跳远、坐位体前屈、1000/800 米、引体向上/仰卧起坐；
- 引体向上与耐力跑加分；
- 南京大学 2400 米单项评分表查询；
- 评分表速查与春季力量对照查询；
- 所有成绩只在浏览器本地计算，不上传。

## 数据核对

`data/college.json` 由 `scripts/extract_tables.py` 从仓库 `static_resources` 中的 XLS 生成。页面默认使用新增的《南京大学春秋体测分数对照表.xls》；右上角“旧版”可切换到原《体测分数对照表.xls》与旧 2400 米表。两个同名“体测分数对照表”文件 SHA-256 完全相同，因此只使用一份；两版秋季大学生综合评分表逐单元格比较无差异。

春秋版 2400 米变化：男生满分档从 10:00 改为 10:30，女生仍为 13:00；新表男女最低档为 50 分，低于最低档按 50 分保底。新增“春季力量对照”查询（引体向上 / 仰卧起坐）。原始资料中的离散档位按“档位之间不插值”实现；Excel 时间按体育成绩语义解释为“分:秒”。

> 这是学习和估算工具，最终成绩以学校体育部/正式成绩系统为准。

## 本地运行

```bash
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

直接双击 HTML 可能因浏览器禁止 `fetch` 本地 JSON 而无法加载数据，建议使用本地 HTTP 服务。
