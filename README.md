# NanNa 体测分数计算器

静态、无后端的大学生体质健康测试成绩计算器，部署于 GitHub Pages 与 `static.lilystudio.space`。

## 功能

- 大学生男/女、大一/大二与大三/大四综合成绩；
- BMI、肺活量、50 米、立定跳远、坐位体前屈、1000/800 米、引体向上/仰卧起坐；
- 引体向上与耐力跑加分；
- 南京大学 2400 米单项评分表查询；
- 评分表速查、暗色/亮色主题、复制摘要、打印 PDF；
- 所有成绩只在浏览器本地计算，不上传。

## 数据核对

`data/college.json` 由 `scripts/extract_tables.py` 从仓库 `static_resources` 中的 XLS 生成。两个同名“体测分数对照表”文件 SHA-256 完全相同，因此只使用一份；大学生表与 `体测标准.docx` 中的大学阶段男生表已交叉核对。原始资料中的离散档位按“档位之间不插值”实现。

2400 米源表把 `10′00″` 等值存成 Excel 时间并使用 `h:mm` 格式；程序按体育成绩语义解释为“分:秒”，而不是小时:分钟。

> 这是学习和估算工具，最终成绩以学校体育部/正式成绩系统为准。

## 本地运行

```bash
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

直接双击 HTML 可能因浏览器禁止 `fetch` 本地 JSON 而无法加载数据，建议使用本地 HTTP 服务。
